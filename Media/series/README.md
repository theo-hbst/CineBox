Create one folder per series/season and place all episodes in it.
Create a 'src' folder inside each series/season folder.
Add .jpg files in the 'src' folder with the same name as the episode.

Example:
```
/Media/series/
└── SeriesName/
    └── Season1/
        ├── Episode1.mkv
        ├── Episode2.mkv
        └── src/
            ├── Episode1.jpg
            └── Episode2.jpg
```
