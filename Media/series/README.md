Créer un dossier par série/saison et y placer tous les épisodes.
Créer un dossier 'src' dans chaque dossier de série/saison.
Ajouter les fichiers .jpg dans le dossier 'src' avec le même nom que l'episode.

Exemple:
```
/Media/series/
└── NomDeLaSerie/
    └── Saison1/
        ├── Episode1.mkv
        ├── Episode2.mkv
        └── src/
            ├── Episode1.jpg
            └── Episode2.jpg
```
